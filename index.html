4tail Case Study

THE CHALLENGE

Manual log analysis during bug bounties is slow and tedious. Grepping through massive files often leads to missed vulnerabilities and wasted operational time.

THE SOLUTION

I developed `4tail`, a Bash-based tool that automates the tailing of logs with real-time color-coding and regex-based filtering specifically tailored for HTTP error codes (403, 500, etc.).

THE RESULT

Increased triage speed by approximately 40% and successfully identified hidden administrative endpoints in a recent engagement.

$ ./4tail.sh -u target.com -w common.txt --filter 403

Dencer Case Study

THE CHALLENGE

Need for a lightweight, CLI-based way to encrypt sensitive evidence files before transfer without relying on heavy third-party GUI tools or risking data exposure.

THE SOLUTION

Built `Dencer` using Python's cryptography library. It utilizes AES-GCM (Galois/Counter Mode) for authenticated encryption, ensuring both absolute confidentiality and data integrity.

Mugetsu Case Study

THE CHALLENGE

Analyzing suspicious files manually is risky and time-consuming. Security teams need rapid initial triage before deep, manual analysis.

THE SOLUTION

Mugetsu provides automated threat analysis by integrating with the VirusTotal API. It scans file hashes and provides instant, color-coded CLI output on malicious indicators.

$ python3 mugetsu.py -f malware_sample.exe
