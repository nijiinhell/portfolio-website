4tail Case Study

THE CHALLENGE

Early-stage bug bounty recon means running the same chain of tools by hand for every target, then stitching their outputs together. It is slow, repetitive, and easy to get wrong.

THE SOLUTION

I developed `4tail`, a Bash script that runs the whole chain from one command: Subfinder for subdomain enumeration, Httpx for live-host detection, Ffuf for content fuzzing, and Nuclei for vulnerability scanning.

THE RESULT

Each stage writes to its own results file (subdomains, alive hosts, fuzzing hits, Nuclei findings) while progress streams to the terminal, so a target goes from domain name to triage-ready output in a single run.

$ chmod +x 4tail.sh
$ ./4tail.sh target.com

Dencer Case Study

THE CHALLENGE

Need for a lightweight, CLI-based way to encrypt sensitive evidence files before transfer without relying on heavy third-party GUI tools or risking data exposure.

THE SOLUTION

Built `Dencer` using Python's cryptography library. It utilizes AES-GCM (Galois/Counter Mode) for authenticated encryption, ensuring both absolute confidentiality and data integrity.

Mugetsu Case Study

THE CHALLENGE

Analyzing suspicious files manually is risky and time-consuming. Security teams need rapid initial triage before deep, manual analysis.

THE SOLUTION

Mugetsu provides automated threat analysis by integrating with the VirusTotal API. It scans file hashes and provides instant, color-coded CLI output on malicious indicators.

$ python3 mugetsu.py -f malware_sample.exe
[+] Detection Ratio: 45/70 (MALICIOUS)
